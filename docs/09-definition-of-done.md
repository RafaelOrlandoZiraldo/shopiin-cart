# Definition of Done

Una tarea se considera terminada cuando:

- Cumple el requerimiento funcional.
- Compila.
- Tests pasan.
- Lint pasa.
- Errores están controlados.
- Inputs están validados.
- No se exponen secretos.
- No hay lógica de negocio significativa en handlers HTTP.
- No se confía en datos económicos del cliente.
- Se actualiza documentación si cambió contrato o arquitectura.
